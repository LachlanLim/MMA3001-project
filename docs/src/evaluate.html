src.evaluate

Measure how well each trained model works, and how much it costs to run.

Training produced four candidate models. This script compares them fairly, chooses one, and gives that one a final exam on photos it has never been judged on. It does no training itself: it loads each saved model (best.pt) and checks photos with it, so it finishes in about a minute.

What is measured, and why

Measurement Plain meaning Why it matters on a packing line
Precision Of the defects reported, how many were real Low precision means good packs are wrongly rejected
Recall Of the real defects, how many were found Low recall means faulty packs reach customers
mAP50 Overall accuracy score from 0 to 1 (see the glossary in src) The main score used to choose the model
GFLOPs Arithmetic needed to check one photo Whether cheaper hardware could run it
Inference time Time for the model to check one photo Whether it keeps up with the line
Peak memory Graphics-card memory used Whether it fits on smaller devices
Training time Hours to train Cost of retraining when new defect types appear
Profile Which operations the processor spends its time on Explains why the speeds are what they are

Speed is measured one photo at a time, as on a line where packs arrive one by one. Ten photos are checked first as a warm-up (the first few are always slow while the graphics card starts up). Then all 120 validation photos are timed, and the median is reported so a single slow photo does not distort it.

Fair testing

The photos are split three ways, like study material, practice exams and a final exam:

  1. The models learned from the 3349 training photos.
  2. The four models are compared on the 120 validation photos, and the best is chosen.
  3. Only the chosen model is tested once on the 80 test photos.

The test photos are kept back until the choice is made. If they were used to choose, the model would be picked partly for luck on those particular photos, and its score would overstate how well it works on new packs.

Usage

Run from the project root, after training all four models:

$ python src/evaluate.py

...
Saved results/model_comparison.csv
Saved results/resolution_comparison.csv

Comparison on the validation photos (AMD Radeon RX 9070 XT):

Model Resolution mAP50 GFLOPs Inference (ms) Memory (MB) Training (h)
YOLO11n 480 0.576 3.6 7.5 32 0.73
YOLO11n 640 0.647 6.4 7.6 39 1.15
YOLO11n 800 0.646 10.1 7.4 50 1.72
YOLO11s 640 0.563 21.4 7.9 109 1.35

YOLO11n at 640 px was chosen: it is the most accurate, and the larger options cost more memory and training time for no gain.

Final test of the chosen model (80 unseen photos):

Defect Defects in test photos Precision Recall mAP50
all 79 0.510 0.488 0.519
unsealed 49 0.664 0.878 0.856
packaging-error 23 0.377 0.522 0.497
twisted-meat 4 0.000 0.000 0.031
loose-meat 3 1.000 0.553 0.694
wrinkle 0 - - -

Reading the results: the model finds 88% of unsealed packs, the most safety-critical defect. It is weak on rare defect types: twisted-meat had only 72 training examples, and its single test score rests on just 4 boxes, so it is not reliable. Wrinkle cannot be tested at all, because the dataset has no wrinkle examples outside the training photos.

A surprising result: every model takes about the same time per photo (7.4 to 7.9 ms), even though the largest needs six times the arithmetic of the smallest.

The profiler explains why:

  • Every model runs the same 88 convolution layers and about 1,200 PyTorch operations per photo. The larger model does more arithmetic inside each operation, but not more operations.
  • Preparing and sending each operation to the graphics card has a fixed cost. Together, these costs come to about 7 ms of processor time per photo, which is roughly the whole inference time.
  • The graphics card finishes the arithmetic faster than the processor can hand it new work, so it spends most of its time waiting.

On this hardware, model size therefore affects memory and training time, not inspection speed. Checking several photos at once (batching) would spread the fixed cost and make the arithmetic matter again.

218def time_inference(model, images, imgsz):
219    """
220    Time single-image inference and record peak GPU memory.
221
222    Images are processed one at a time (batch size 1), which matches an
223    inspection line where each pack is checked as it arrives. The GPU is
224    synchronised around each call so the timer measures finished work.
225
226    Args:
227        model (YOLO): Trained model.
228        images (list[PIL.Image.Image]): Images preloaded into memory, so
229            disk reading is not included in the timing.
230        imgsz (int): Input resolution in pixels.
231
232    Returns:
233        dict: Median end-to-end time per image (``end_to_end_ms``,
234        including pre- and post-processing), median network-only time
235        (``inference_ms``) and peak GPU memory (``peak_memory_mb``).
236    """
237    for image in images[:WARMUP_IMAGES]:
238        model.predict(image, imgsz=imgsz, device=DEVICE, verbose=False)
239
240    torch.cuda.reset_peak_memory_stats()
241    end_to_end_ms = []
242    inference_ms = []
243
244    for image in images:
245        torch.cuda.synchronize()
246        start = time.perf_counter()
247
248        result = model.predict(image, imgsz=imgsz, device=DEVICE, verbose=False)[0]
249
250        torch.cuda.synchronize()
251        end_to_end_ms.append((time.perf_counter() - start) * 1000)
252
253        # Ultralytics also times the network forward pass on its own
254        inference_ms.append(result.speed["inference"])
255
256    # The median is less affected by occasional slow calls than the mean
257    return {
258        "end_to_end_ms": statistics.median(end_to_end_ms),
259        "inference_ms": statistics.median(inference_ms),
260        "peak_memory_mb": torch.cuda.max_memory_allocated() / 1e6,
261    }

264def profile_inference(model, image, imgsz, name):
265    """
266    Profile where the processor's time goes when checking one photo.
267
268    Uses the PyTorch profiler to record every operation PyTorch runs
269    (convolutions, additions, reshapes and so on) while checking the same
270    photo ``PROFILE_RUNS`` times. Each operation has a fixed cost to
271    prepare and send to the graphics card, however little arithmetic it
272    does. Counting operations therefore shows how much of the time is
273    this fixed overhead rather than arithmetic.
274
275    Only processor-side (CPU) activity is recorded. The profiler cannot
276    record work on the graphics card itself for AMD cards on Windows.
277    The profiler also slows the code down, so its times are useful for
278    comparing operations, not as absolute speeds.
279
280    Args:
281        model (YOLO): Trained model.
282        image (PIL.Image.Image): Photo to check.
283        imgsz (int): Input resolution in pixels.
284        name (str): Experiment name, used for the output file name.
285
286    Returns:
287        dict: PyTorch operations per photo (``operations_per_image``,
288        including operations called inside other operations), convolution
289        layers run per photo (``convolutions_per_image``), and processor
290        time per photo while profiled (``profiled_cpu_ms``).
291
292    Example:
293        For YOLO11n at 640 px, the saved breakdown in
294        ``results/profiles/yolo11n_640.txt`` starts with the operations
295        that took the most processor time:
296
297        ```text
298        Name                       Self CPU %   ...   # of Calls
299        aten::miopen_convolution       52.35%   ...         1620
300        aten::nonzero                   7.17%   ...           60
301        ...
302        ```
303    """
304    for _ in range(WARMUP_IMAGES):
305        model.predict(image, imgsz=imgsz, device=DEVICE, verbose=False)
306
307    with profile(activities=[ProfilerActivity.CPU]) as prof:
308        for _ in range(PROFILE_RUNS):
309            model.predict(image, imgsz=imgsz, device=DEVICE, verbose=False)
310
311    events = prof.key_averages()
312
313    # "aten::" operations are PyTorch's own building blocks
314    operations = sum(e.count for e in events if e.key.startswith("aten::"))
315    convolutions = sum(e.count for e in events if e.key == "aten::conv2d")
316    cpu_ms = sum(e.self_cpu_time_total for e in events) / 1000
317
318    summary = {
319        "operations_per_image": round(operations / PROFILE_RUNS),
320        "convolutions_per_image": round(convolutions / PROFILE_RUNS),
321        "profiled_cpu_ms": round(cpu_ms / PROFILE_RUNS, 1),
322    }
323
324    PROFILES_DIR.mkdir(parents=True, exist_ok=True)
325    with open(PROFILES_DIR / f"{name}.txt", "w", encoding="utf-8") as f:
326        f.write(f"PyTorch profile: {name}, {PROFILE_RUNS} photos at {imgsz} px\n")
327        for key, value in summary.items():
328            f.write(f"{key}: {value}\n")
329        f.write("\n")
330        f.write(events.table(sort_by="self_cpu_time_total", row_limit=15))
331
332    return summary

335def training_hours(run_name):
336    """
337    Read the total training time from an Ultralytics results.csv.
338
339    The ``time`` column holds the elapsed seconds at the end of each
340    epoch. It restarts from zero when training is resumed, so each
341    training session is added separately.
342
343    Args:
344        run_name (str): Folder name inside ``runs/detect/results/training``.
345
346    Returns:
347        float: Training time in hours, or None if results.csv is missing.
348    """
349    results_csv = TRAINING_DIR / run_name / "results.csv"
350
351    if not results_csv.is_file():
352        return None
353
354    with open(results_csv, "r", encoding="utf-8") as f:
355        times = [float(row["time"].strip()) for row in csv.DictReader(f)]
356
357    # A resumed run restarts the clock, so add up each session's last time
358    total_seconds = times[-1]
359    for previous, current in zip(times, times[1:]):
360        if current < previous:
361            total_seconds += previous
362
363    return total_seconds / 3600

370def evaluate_experiment(name, label, imgsz, run_name, images):
371    """
372    Measure the accuracy and cost of one trained model.
373
374    Args:
375        name (str): Experiment name, e.g. ``"yolo11n_640"``.
376        label (str): Model label for the tables, e.g. ``"YOLO11n"``.
377        imgsz (int): Input resolution in pixels.
378        run_name (str): Ultralytics training run folder.
379        images (list[PIL.Image.Image]): Validation images for timing.
380
381    Returns:
382        dict: One row of the comparison tables.
383
384    Raises:
385        FileNotFoundError: If the run has no best.pt weights.
386    """
387    weights = TRAINING_DIR / run_name / "weights" / "best.pt"
388
389    if not weights.is_file():
390        raise FileNotFoundError(f"No trained weights at {weights}.")
391
392    print(f"\n=== {name} ===")
393
394    # Free memory left over from the previous model, then record what is
395    # still in use, so it is not counted as this model's memory
396    gc.collect()
397    torch.cuda.empty_cache()
398    baseline_mb = torch.cuda.memory_allocated() / 1e6
399    print(f"GPU memory in use before loading: {baseline_mb:.0f} MB")
400
401    model = YOLO(str(weights))
402
403    metrics = validate(model, imgsz, "val", f"{name}_val")
404    timing = time_inference(model, images, imgsz)
405    profiling = profile_inference(model, images[0], imgsz, name)
406
407    # Count the fused model (BatchNorm folded into the convolutions),
408    # which is the version that actually runs during inference
409    model.fuse()
410    parameters = sum(p.numel() for p in model.model.parameters())
411    gflops = get_flops(model.model, imgsz)
412
413    # Rate of useful computation actually achieved during the forward pass
414    achieved_gflops_per_s = gflops / (timing["inference_ms"] / 1000)
415
416    hours = training_hours(run_name)
417
418    return {
419        "model": label,
420        "resolution": imgsz,
421        "precision": round(metrics.box.mp, 3),
422        "recall": round(metrics.box.mr, 3),
423        "mAP50": round(metrics.box.map50, 3),
424        "mAP50_95": round(metrics.box.map, 3),
425        "parameters": parameters,
426        "gflops": round(gflops, 1),
427        "inference_ms": round(timing["inference_ms"], 2),
428        "end_to_end_ms": round(timing["end_to_end_ms"], 2),
429        "achieved_gflops_per_s": round(achieved_gflops_per_s),
430        "peak_memory_mb": round(timing["peak_memory_mb"] - baseline_mb),
431        "operations_per_image": profiling["operations_per_image"],
432        "convolutions_per_image": profiling["convolutions_per_image"],
433        "training_hours": round(hours, 3) if hours is not None else "",
434    }

437def evaluate_test_split(name, imgsz, run_name):
438    """
439    Evaluate the selected model once on the withheld test split.
440
441    Args:
442        name (str): Experiment name.
443        imgsz (int): Input resolution in pixels.
444        run_name (str): Ultralytics training run folder.
445
446    Returns:
447        list[dict]: An ``all`` row followed by one row per class that
448        appears in the test split.
449    """
450    print(f"\n=== Final test: {name} ===")
451    model = YOLO(str(TRAINING_DIR / run_name / "weights" / "best.pt"))
452    metrics = validate(model, imgsz, "test", f"{name}_test", plots=True)
453
454    test_images = list_images(DATASET_DIR / "test" / "images")
455
456    rows = [{
457        "class": "all",
458        "images": len(test_images),
459        "instances": int(metrics.nt_per_class.sum()),
460        "precision": round(metrics.box.mp, 3),
461        "recall": round(metrics.box.mr, 3),
462        "mAP50": round(metrics.box.map50, 3),
463        "mAP50_95": round(metrics.box.map, 3),
464    }]
465
466    for row in metrics.summary(decimals=3):
467        rows.append({
468            "class": row["Class"],
469            "images": int(row["Images"]),
470            "instances": int(row["Instances"]),
471            "precision": row["Box-P"],
472            "recall": row["Box-R"],
473            "mAP50": row["mAP50"],
474            "mAP50_95": row["mAP50-95"],
475        })
476
477    return rows

496def main():
497    """
498    Evaluate every experiment and save the comparison tables.
499
500    Raises:
501        RuntimeError: If no GPU is available, since timing results on a
502            CPU would not be comparable with the training hardware.
503    """
504    if not torch.cuda.is_available():
505        raise RuntimeError("A GPU is required for consistent timing results.")
506
507    print(f"GPU: {torch.cuda.get_device_name(DEVICE)}")
508
509    # Preload the validation images so timing excludes disk reads
510    images = [
511        Image.open(path).convert("RGB")
512        for path in list_images(DATASET_DIR / "valid" / "images")
513    ]
514
515    # The first model run on the GPU also sets up memory that stays in use
516    # afterwards. Run one model briefly first, so this one-off memory is not
517    # counted against whichever model happens to be measured first.
518    _, _, imgsz, run_name = EXPERIMENTS[0]
519    warmup_model = YOLO(str(TRAINING_DIR / run_name / "weights" / "best.pt"))
520    warmup_model.predict(images[0], imgsz=imgsz, device=DEVICE, verbose=False)
521    del warmup_model

def time_inference(model, images, imgsz): 
219def time_inference(model, images, imgsz):
220    """
221    Time single-image inference and record peak GPU memory.
222
223    Images are processed one at a time (batch size 1), which matches an
224    inspection line where each pack is checked as it arrives. The GPU is
225    synchronised around each call so the timer measures finished work.
226
227    Args:
228        model (YOLO): Trained model.
229        images (list[PIL.Image.Image]): Images preloaded into memory, so
230            disk reading is not included in the timing.
231        imgsz (int): Input resolution in pixels.
232
233    Returns:
234        dict: Median end-to-end time per image (``end_to_end_ms``,
235        including pre- and post-processing), median network-only time
236        (``inference_ms``) and peak GPU memory (``peak_memory_mb``).
237    """
238    for image in images[:WARMUP_IMAGES]:
239        model.predict(image, imgsz=imgsz, device=DEVICE, verbose=False)
240
241    torch.cuda.reset_peak_memory_stats()
242    end_to_end_ms = []
243    inference_ms = []
244
245    for image in images:
246        torch.cuda.synchronize()
247        start = time.perf_counter()
248
249        result = model.predict(image, imgsz=imgsz, device=DEVICE, verbose=False)[0]
250
251        torch.cuda.synchronize()
252        end_to_end_ms.append((time.perf_counter() - start) * 1000)
253
254        # Ultralytics also times the network forward pass on its own
255        inference_ms.append(result.speed["inference"])
256
257    # The median is less affected by occasional slow calls than the mean
258    return {
259        "end_to_end_ms": statistics.median(end_to_end_ms),
260        "inference_ms": statistics.median(inference_ms),
261        "peak_memory_mb": torch.cuda.max_memory_allocated() / 1e6,
262    }

def profile_inference(model, image, imgsz, name): 
265def profile_inference(model, image, imgsz, name):
266    """
267    Profile where the processor's time goes when checking one photo.
268
269    Uses the PyTorch profiler to record every operation PyTorch runs
270    (convolutions, additions, reshapes and so on) while checking the same
271    photo ``PROFILE_RUNS`` times. Each operation has a fixed cost to
272    prepare and send to the graphics card, however little arithmetic it
273    does. Counting operations therefore shows how much of the time is
274    this fixed overhead rather than arithmetic.
275
276    Only processor-side (CPU) activity is recorded. The profiler cannot
277    record work on the graphics card itself for AMD cards on Windows.
278    The profiler also slows the code down, so its times are useful for
279    comparing operations, not as absolute speeds.
280
281    Args:
282        model (YOLO): Trained model.
283        image (PIL.Image.Image): Photo to check.
284        imgsz (int): Input resolution in pixels.
285        name (str): Experiment name, used for the output file name.
286
287    Returns:
288        dict: PyTorch operations per photo (``operations_per_image``,
289        including operations called inside other operations), convolution
290        layers run per photo (``convolutions_per_image``), and processor
291        time per photo while profiled (``profiled_cpu_ms``).
292
293    Example:
294        For YOLO11n at 640 px, the saved breakdown in
295        ``results/profiles/yolo11n_640.txt`` starts with the operations
296        that took the most processor time:
297
298        ```text
299        Name                       Self CPU %   ...   # of Calls
300        aten::miopen_convolution       52.35%   ...         1620
301        aten::nonzero                   7.17%   ...           60
302        ...
303        ```
304    """
305    for _ in range(WARMUP_IMAGES):
306        model.predict(image, imgsz=imgsz, device=DEVICE, verbose=False)
307
308    with profile(activities=[ProfilerActivity.CPU]) as prof:
309        for _ in range(PROFILE_RUNS):
310            model.predict(image, imgsz=imgsz, device=DEVICE, verbose=False)
311
312    events = prof.key_averages()
313
314    # "aten::" operations are PyTorch's own building blocks
315    operations = sum(e.count for e in events if e.key.startswith("aten::"))
316    convolutions = sum(e.count for e in events if e.key == "aten::conv2d")
317    cpu_ms = sum(e.self_cpu_time_total for e in events) / 1000
318
319    summary = {
320        "operations_per_image": round(operations / PROFILE_RUNS),
321        "convolutions_per_image": round(convolutions / PROFILE_RUNS),
322        "profiled_cpu_ms": round(cpu_ms / PROFILE_RUNS, 1),
323    }
324
325    PROFILES_DIR.mkdir(parents=True, exist_ok=True)
326    with open(PROFILES_DIR / f"{name}.txt", "w", encoding="utf-8") as f:
327        f.write(f"PyTorch profile: {name}, {PROFILE_RUNS} photos at {imgsz} px\n")
328        for key, value in summary.items():
329            f.write(f"{key}: {value}\n")
330        f.write("\n")
331        f.write(events.table(sort_by="self_cpu_time_total", row_limit=15))
332
333    return summary

def training_hours(run_name): 
336def training_hours(run_name):
337    """
338    Read the total training time from an Ultralytics results.csv.
339
340    The ``time`` column holds the elapsed seconds at the end of each
341    epoch. It restarts from zero when training is resumed, so each
342    training session is added separately.
343
344    Args:
345        run_name (str): Folder name inside ``runs/detect/results/training``.
346
347    Returns:
348        float: Training time in hours, or None if results.csv is missing.
349    """
350    results_csv = TRAINING_DIR / run_name / "results.csv"
351
352    if not results_csv.is_file():
353        return None
354
355    with open(results_csv, "r", encoding="utf-8") as f:
356        times = [float(row["time"].strip()) for row in csv.DictReader(f)]
357
358    # A resumed run restarts the clock, so add up each session's last time
359    total_seconds = times[-1]
360    for previous, current in zip(times, times[1:]):
361        if current < previous:
362            total_seconds += previous
363
364    return total_seconds / 3600
